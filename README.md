# 1Alpha1's Minecraft Folio (@1Alphaaa1)

An interactive 3D Minecraft portfolio custom-tailored for YouTube gaming creator **[1Alpha1 (@1Alphaaa1)](https://www.youtube.com/@1Alphaaa1)**, based on the Three.js Minecraft Folio architecture.

---

## 🌐 Live Server
Run locally at:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🚀 Running the Project
```powershell
node server.js
```
or
```powershell
npm start
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
